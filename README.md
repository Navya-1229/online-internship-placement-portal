# Online Internship & Placement Preparation Portal

## Project Description

The Online Internship & Placement Preparation Portal is a web-based platform designed to help students find internship opportunities and prepare for placements.

The system allows students to search and apply for internships, take aptitude tests, track their preparation progress, and view performance analytics.

Recruiters can post internship opportunities and manage student applications, while administrators can manage users, internships, tests, and questions.

## Features

### Student
- Student registration and login
- Profile management
- Internship search and filtering
- Internship application
- Application status tracking
- Online aptitude tests
- Automatic test evaluation
- Test history
- Preparation progress tracking
- Performance analytics

### Recruiter
- Recruiter registration and login
- Internship posting
- Internship management
- View student applications
- Shortlist/reject candidates
- Update application status

### Admin
- User management
- Internship management
- Aptitude test management
- Question management
- Application monitoring
- System analytics

## Technology Stack

- Frontend: React.js
- Backend: Node.js, Express.js
- Database: MongoDB
- APIs: REST API
- Version Control: Git and GitHub
